# 마이페이지 기능 명세

복잡한 내용 없이, 화면별 핵심 기능과 코드의 역할을 간단히 요약했습니다.

## 1. 마이페이지 화면
* **주요 기능:** 내 구글 계정 정보와 현재 배정된 학생회 직책, 상세 권한을 조회합니다.
* **UI 요소 (`MyPage_View.html`):**
  - **내 정보:** 이메일, 이름, 소속을 표시합니다.
  - **내 역할 & 업무영역:** 회장/총무 등 직책과 접근 가능한 탭(회계, 행사 등)을 칩 형태로 보여줍니다.
  - **내 권한:** 각 업무별로 내가 '조회'만 가능한지, '수정/승인'도 가능한지 상세히 보여줍니다.

## 2. 핵심 코드 (`mypage_js.html`)
* **데이터 가져오기 (`initializeMyPage`):** 
  - 페이지가 열릴 때 '내 기본 정보 API'와 '권한 API' 2개를 동시에 호출해 속도를 높입니다.
* **화면 그리기 (`render...` 함수들):** 
  - 서버에서 받은 데이터를 HTML 화면(DOM)의 각 위치에 맞게 텍스트로 꽂아 넣습니다.
* **권한 변환 (`grantLabels_`):** 
  - 서버의 영어 코드(`view`, `edit`)를 한글(`조회`, `등록·수정`)로 보기 좋게 바꿔줍니다.
