## 핵심 동작

### 1. 데이터는 한 번만 불러온다
- 로그인 시 `loadAllData()`로 사용자·역할·권한·부서를 한 번에 받는다.
- 페이지를 옮겨도 서버를 다시 치지 않는다.
- **다시 불러오기**는 설정 홈에만 있다.
- 저장할 때만 시트를 갱신하고 캐시를 맞춘다.

### 2. 두 개의 Google Sheets

| [학생회_운영_2026](https://docs.google.com/spreadsheets/d/1EI8MbFx2HSuizl0QFygRAZydYiv77W-6pQO10mRN55E/edit) | `_설정`(학년도·운영기간), `학기기준`. 장부·회비·행사는 이후 화면에서 사용 |

웹앱은 **배포 계정(`woolim0203@gmail.com`) 권한**으로 시트를 연다. 두 시트 모두 이 계정에 **편집자 공유**가 되어 있어야 읽기/저장이 된다. 팀원이 웹앱만 쓰는 경우 시트 공유는 필요 없다.

### 3. 페이지 권한
업무 권한 설정에서 **조회**를 켠 페이지만 사이드바에 보이고, URL로 들어가도 막는다.

- 대상 페이지: 메인화면, 장부관리, 학생회비관리, 행사복지관리, 설정
- `role_admin`(시스템 관리자)은 전 페이지 가능
- 그 외 역할은 체크한 페이지만 가능

### 4. 설정 > 부서 (신규)
설정 목록 **맨 위**. 클릭 수정 없음, 보기 전용 조직도.

- 위: 회장 / 부회장
- 아래: 부서별 국장 → 차장 → 국원 (위원회는 위원장 → 부위원장 → 위원)
- 각 계정에 역할 태그와 페이지 권한(메인·장부·회비·행사·설정)
- 상단 요약: 전체 계정, 활성 부원, 부서 수, 역할 수

직급은 역할명에 `회장`, `부회장`, `국장`, `차장` 등이 있는지로 나눈다.

## API (COM_API v1)

1차 API 시트 기준으로 `apiV1_*`를 맞춰 두었다.

구현: 로그인/사용자/역할/권한/내정보/학년도/부서/담당자/코드/감사로그  
스텁·예정: 알림 설정, 파일 업로드·조회

프론트 집계: `loadAllData`, `connectDriveFolder`, `connectSpreadsheet`

## 시트 스키마 매핑 (사용자_2026)

- **사용자** — Google이메일이 ID. 학번·연락처·부서ID·활성여부
- **사용자역할** — 이메일 × 역할ID, 배정상태(활성/해제)
- **역할** — 시스템역할여부 = 보호(수정 잠금)
- **권한** — 업무영역 × 행위 카탈로그 (덮어쓰되, 페이지 권한 항목은 코드에서 보강)
- **역할권한** — 역할에 부여된 권한ID
- **권한감사로그** — 저장 시 이력

부서 시트가 비어 있으면 조직도에 기본 부서 칸(사무국·운영국 등)을 보여 주고, 소속 없는 계정은 **미배정**에 둔다.
