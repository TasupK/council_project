# 메인 및 로그인 페이지 기능 명세

복잡한 내용 없이, 화면별 핵심 기능과 코드의 역할을 간단히 요약했습니다.

## 1. 로그인 화면
* **주요 기능:** 구글 계정으로 로그인하여 시스템 사용 권한을 확인합니다.
* **핵심 코드 (`login_auth_js.html`):**
  - **로그인 처리:** 클릭 시 서버에서 현재 구글 이메일을 가져와 명부 DB와 대조합니다.
  - **에러 처리:** 권한이 없으면 알림창을 띄우고, 통과되면 메인 화면으로 이동합니다.

## 2. 메인 화면 (대시보드)
* **주요 기능:** 업무 현황을 한눈에 보고, 원하는 메뉴로 빠르게 넘어갈 수 있습니다.
* **UI 요소 (`Main_View.html`):**
  - **주요 현황:** 학생회비, 행사, 회계 관련 '확인 대기' 건수들을 카드로 요약해서 보여줍니다.
  - **빠른 실행:** 수입/지출 등록 등 자주 쓰는 메뉴의 단축 버튼들입니다.
* **핵심 코드 (`app_shell_js.html`):**
  - **네비게이션:** 좌측 메뉴 클릭 시 해당 페이지로 URL을 이동시킵니다.
  - **권한 제어:** 서버에서 유저 권한을 확인한 뒤, 접근 불가능한 메뉴는 화면에서 숨깁니다.
