### Figma·기획에서 정의한 UX (→ main UI와 대응)

**행사 목록 (`event_home`)**

- 상단 breadcrumb + **← 뒤로가기** + 「행사 목록」타이틀 + **＋ 행사 생성** CTA
- 필터: 키워드, 담당자, 진행 일자, 유형, 행사 상태, 종료 포함 토글
- **상태별 KPI 요약** 카드 + 행사 테이블 + 페이지 이동
- 목록 행 → 상세 진입(더블클릭/선택)

**행사 상세 (`event_detail`)**

- 상단: 「행사복지관리 상세」, **목록으로** / **＋ 행사 정보 수정**
- **히어로 영역**: 행사명, 상태 배지, 일시·담당자 등 메타
- **KPI 5종**: 전체 신청자 / 승인 참가자 / 참가비 입금 완료 / 실제 출석자 / 현재 잔액
- **탭 구조**: 기본정보 · 신청자 · 참가비·출석 · 결산 · 환불
- 탭별 업무(승인·반려, 출석 변경, 결산·환불)를 한 화면에서 통합 관리

### 기획·검수 활동
